# Practica de Mezcla Directa en Java

## Descripcion
Esta practica consiste en realizar la intercalacion de dos archivos de texto utilizando Java, mediante el metodo de Mezcla Directa (Straight Merge).

## Objetivo
Comprender el funcionamiento de la mezcla de archivos y la comparacion de numeros para obtener una secuencia ordenada.

## Herramientas utilizadas
- Java
- IntelliJ IDEA
- GitHub

## Archivos del proyecto
- MezclaDirectaPractica.java
- f1.txt
- f2.txt
- f3.txt

## Datos de prueba

f1.txt:
45

f2.txt:
12

## Resultado esperado

f3.txt:
12
45

## Ejecucion
El programa se ejecuta desde IntelliJ IDEA utilizando la clase MezclaDirectaPractica.

## Lenguaje
Java
